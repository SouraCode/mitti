# Live SEO Audit Checklist for Mitti Rituals

Use this checklist before launch and after any major marketing or site update.

## 1) Technical SEO
- [ ] Submit the production domain to Google Search Console
- [ ] Verify ownership with HTML tag, DNS, or Google Analytics property
- [ ] Confirm the site is served over HTTPS only
- [ ] Ensure `robots.txt` points to the live domain and sitemap URL
- [ ] Confirm `sitemap.xml` includes all published live URLs
- [ ] Check canonical tags on every page and remove duplicates
- [ ] Inspect page titles and meta descriptions for length and uniqueness
- [ ] Make sure there is one H1 on every page and heading structure follows a logical order
- [ ] Validate there are no broken internal links or missing routes

## 2) Content SEO
- [ ] Each product page has a unique title, relevant description, and clean slug
- [ ] Category and landing pages target the correct buyer intent
- [ ] Product copy includes ingredient and benefit language that helps search discovery
- [ ] Blog or editorial content, if added later, should link back to category and product pages
- [ ] Review snippets are encouraged where real customer feedback is available

## 3) Image and Media SEO
- [ ] All product and lifestyle images include meaningful alt text
- [ ] Images are compressed and served in next-gen formats where possible
- [ ] Large hero and product imagery is lazy-loaded where appropriate
- [ ] Open Graph image and social share previews look correct on the live URL

## 4) Performance and Core Web Vitals
- [ ] Mobile page speed is measured with Lighthouse and PageSpeed Insights
- [ ] Largest Contentful Paint is under 2.5s on mobile
- [ ] Interaction to Next Paint is under 200ms
- [ ] Cumulative Layout Shift stays below 0.1
- [ ] JavaScript bundles are reviewed after launches or large design changes

## 5) Structured Data
- [ ] Product schema is present on product detail pages
- [ ] Organization schema is present site-wide
- [ ] Review schema is added when approved customer reviews are available
- [ ] Use the Rich Results Test before publishing new schema patterns

## 6) Search visibility
- [ ] URLs are clean, readable, and keyword-friendly
- [ ] Search console is checked for indexing issues and manual actions
- [ ] Internal links help users navigate between story, shop, guide, and product pages
- [ ] A backlink strategy is defined using brand mentions, PR, creator partnerships, and category directories

## 7) Backlink plan
- [ ] Add your brand to relevant beauty, wellness, and sustainability directories
- [ ] Reach out to micro-influencers and skincare creators for product gifting and review links
- [ ] Publish useful content that naturally attracts links from editorial and community sites
- [ ] Monitor referral traffic and backlink quality every month

## 8) Final launch check
- [ ] Test on desktop and mobile across major browsers
- [ ] Review all routes and page titles manually before launch
- [ ] Check forms, cart, login, and checkout flows in the live environment
- [ ] Confirm analytics events and conversion tracking are active
- [ ] Re-run a Lighthouse audit and import site to Search Console after deployment
